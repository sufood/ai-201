# Core Skills for AI 201: LLM & Gen AI Focus

This repository contains the materials for the "Core Skills for AI 201: LLM & Gen AI Focus" training course.

## Course Outline

### 1. LLM and Gen AI Foundations
*   **How LLMs Work:** Architecture (especially transformers), training processes, and scaling laws.
*   **Types of Generative Models:** Text, multimodal, and other generative architectures.
*   **Responsible AI:** Principles and governance; fairness, bias, privacy, transparency, APRA and ISM compliance contexts for Australia.

### 2. Practical LLM Application Skills
*   **Prompt Engineering:** Techniques for crafting effective prompts (prompt sandwiches, few-shot/fine-tuning, iterative refinement) to drive desired outputs from LLMs.
*   **Interaction with AI APIs:** Building applications using LLM APIs (e.g., OpenAI, Vertex AI, Azure OpenAI), including basic querying and advanced usage like conversation state management.
*   **Fine-Tuning & Adaptation:** Transfer learning, domain adaptation, and efficient fine-tuning strategies such as LoRA or parameter-efficient methods.
*   **Integration into Apps:** Hands-on experience integrating LLMs into web apps (e.g., using Python and Streamlit) and deploying models as cloud-native services.

### 3. Advanced Topics & Project Lifecycle
*   **Evaluating and Troubleshooting LLMs:** Applying metrics for text quality, relevance, faithfulness, and robustness; addressing hallucinations.
*   **RAG (Retrieval-Augmented Generation) Systems:** Building and optimizing retrieval-based architectures for enterprise Q&A and knowledge management.
*   **Compliance & Security in Gen AI:** Best practices for securing LLM pipelines, audit logging, and managing sensitive data.
*   **AI Ethics and Governance:** In-depth case studies on misuse prevention, model risk, and aligning LLMs with organizational policy.

### 4. Capstone and Assessment
*   **Case-Based Projects:** Scenario-driven labs (e.g., building internal expert chatbots, regulatory document analysis, custom enterprise knowledge retrieval) that reinforce all technical and governance skills.
*   **Strategy Prompt Library:** Students develop and curate a personal library of advanced prompts for common enterprise tasks and audits.
*   **Reflection & Assessment:** Peer review, capstone presentations, and practical checklists for model governance.

## Highly Recommended Supporting Skills
*   **Python Programming:** For building, integrating, and automating LLM solutions.
*   **OOP and Modular Coding:** Maintainability and reusability in codebases for generative AI applications.
*   **Version Control (Git, GitHub):** Collaboration and traceability for notebooks, code, and experiments.
*   **Cloud AI Platform Basics:** Experience with deploying LLM workloads in GCP, Azure, or AWS environments, including managed ML services.
